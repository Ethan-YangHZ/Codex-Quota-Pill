# 测试报告 · 0.1.0 安全隔离版

日期：2026-10-23。Windows build 26200 / 25H2，x64。便携 SDK 8.0.426，经微软发布清单 SHA512 校验。当前显示器 2560 × 1600，150% 缩放，工作区顶部 48 px。

## 已完成

- Release 编译及 win-x64 自包含发布成功，无编译错误、警告；运行不依赖系统安装的 .NET。
- 48 项自动检查全部通过，完整输出位于项目 `02_过程产物/test-results.txt`。
- 吸附几何覆盖：顶/左/右，离边恢复，底部约束，负坐标，200% 缩放及极小工作区。
- 额度语义覆盖：剩余换算、primary/secondary 颠倒、Codex 标准组优先、未知/专用组、15 分钟窗口、缺失/歧义窗口、无效重置、Unix 秒、分钟向上取整、过期后不伪造恢复、颜色阈值。
- 独立模拟子进程覆盖：初始化顺序、连接复用、通知和无关 id、拒绝凭证刷新、错误脱敏、取消/超时；所有模拟子进程已回收。
- 调度覆盖：60 秒周期、断网失败缓存、指数退避、手动刷新节流、恢复后清除错误、reset 触发单次提前查询。
- 存储覆盖：位置和方向往返、最小化缓存、过期/未来缓存拒绝、损坏文件及不可写路径降级。
- 发布版窗口测试：横向、左右纵向和顶部渲染；显示/隐藏；前台窗口句柄在显示/移动/隐藏后保持不变。
- 发布版单实例测试：首实例运行中再次启动，第二个实例正常退出，首实例继续运行；随后首实例自行正常退出，退出码 0。
- 发布版正常模式没有真实额度请求或 Codex 子进程。默认正确显示两项 `--` 和 `重置 · --`。
- 一次短期观测工作集约 60.9 MiB；这是单次冷启动附近读数，不是长期性能保证。

## 证据与范围

`Windows-x64/artifacts/` 下 JSON 记录 `focusPreserved=true`、隐藏后重显成功、退出码和单实例结果。PNG 是从本程序 WPF Visual 导出的渲染图，**不是桌面截图**，不包含 Codex 或其他软件内容，也不能用于证明 DWM 背后实际磨砂效果。

没有向 Codex 窗口发送输入、点击、滚动或快捷键，没有注入、改窗口、暂停/终止其进程、改文件、登录或占用交互会话。当前任务仍可继续交互，但这不是对所有 Codex 长任务无干扰的全面实机认证。

## 未验证或受限

- **两个真实额度均未读取成功。** 没有真实 app-server 连接、账户/网络兼容性或真实断网恢复的证据。发布版安全封锁是有意保留的限制。
- 本机只有一台显示器；多显示器负坐标和 200% DPI 只有逻辑测试，跨不同 DPI 显示器拖动仍需实机验收。
- 未对真实 Codex 输入、滚动、快捷键进行操作测试，以遵守不得操作其他应用的要求。焦点证据只证明本次自动窗口操作未更换前台窗口，不能覆盖所有系统交互。
- 鼠标拖动事件、托盘菜单代码及窗口移动已实现；自动测试直接执行本组件动作，没有模拟全桌面的真实鼠标手势。吸附手感、悬停和托盘右键点击仍需要用户实测。
- DWM Acrylic、透明与系统阴影依赖 Windows 合成器、系统透明效果及远程桌面条件。申请原生磨砂，保留深色半透明渐变回退；没有拍摄桌面来验证实际背景模糊及阴影强度。
- 未进行长时间驻留、实际热拔插显示器、睡眠唤醒或不同 Windows 主题下的验收。未签名，Windows 可能显示未知发布者。
- 自包含目录约 145 MiB；体积用于携带 .NET/WPF 运行时，程序自身托管程序集约 59 KiB。

## 安全异常

Codex 版本/帮助检查出现临时目录清理和 PATH 别名写入尝试，沙箱拒绝；立即停止该可执行文件的后续调用。SDK 首次运行证书提示及核查情况详见 INTERFACE.md。没有为了消除这些异常而清理系统、修改已有 Codex 或重启任何服务。

交付结论：可运行的 UI 与安全隔离版本，满足已验证的窗口及模拟数据行为；**不宣称已经完成真实额度监控或所有硬件组合的全面测试。**
